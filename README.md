# mp4-converter

![Python](https://img.shields.io/badge/Python-3.9+-blue)

把中文课程/讲座视频批量转换为高质量交付物：无损 FLAC 音频 → ASR 转录 → LLM 反幻觉校准 → 排版精良的 HTML 文章。

> **语言适配说明**：内置模型（FunASR Paraformer-large、VAD、标点模型均为 zh-cn 版本）针对**中文语音**优化，适合中文课程、讲座、会议。其他语言请自行替换 `scripts/transcribe.py` 中的模型 ID。

## 特性

- **无损音频提取** — ffmpeg 提取原生采样率 FLAC（s24, 44.1kHz）
- **中文优化转录** — FunASR Paraformer-large + VAD + 标点恢复，Apple Silicon 上 MPS GPU 加速（RTF 0.016，10 分钟音频约 10 秒）
- **反幻觉校准** — 严格逐句校准：只修同音错字、加标点、统一术语，绝不添加原文没有的内容
- **领域可定制** — 只需重写一个术语表文件 `references/terminology.md`
- **断点续跑 + 并行** — 三阶段流水线，已完成的文件自动跳过
- **零成本转录** — ASR 本地运行免费；LLM 校准+校对约 ¥0.12-0.15/文件

## Pipeline

```
mp4 ──ffmpeg──▶ .flac ──FunASR──▶ .txt ──DeepSeek 校准──▶ .html ──DeepSeek 校对──▶ _verified.html
                                                   └──（可选）要点提炼──▶ html_summary/<章节>.html
```

## 快速开始

### 1. 安装依赖

```bash
brew install ffmpeg                       # 音频提取
pip3 install funasr torch torchaudio     # ASR（首次运行自动下载约 1.3GB 模型）
pip3 install openai                      # DeepSeek API
```

### 2. 设置 API Key

```bash
export DEEPSEEK_API_KEY="sk-xxx"
```

### 3. 运行

```bash
# 单个视频：mp4 → 最终 _verified.html
python3 scripts/run_pipeline.py --single "path/to/视频.mp4"

# 批量（推荐，三阶段并行流水线）
python3 scripts/run_parallel.py --all --root "path/to/你的视频库"

# 可选：章节要点提炼（去除暖场/废话/重复，每章节输出一份要点 HTML）
python3 scripts/summarize.py --all
```

将同一门课/章节的视频放进同一子文件夹，输出会按源文件夹分子目录保存到 `audio/`、`txt/`、`html/`、`html_summary/`。失败记录在 `pipeline_errors.log`，不影响其他文件。

## 定制你的领域

唯一需要改的文件是 `references/terminology.md`：按「常见误识 → 正确写法」列出你领域的同音错字、术语、人名、课程名，运行时自动注入 calibrate 和 polish 的 prompt。示例：

| 常见误识 | 正确写法 | 说明 |
|----------|----------|------|
| 三之柱、三只柱 | 三支柱 | HR 三支柱模型 |
| 斯达法则、四大法则 | STAR法则 | 行为面试法 |
| 示例误识、示例勿实 | 示例务实 | 示例：替换为你的课程/方法名 |

> 保留文件末尾的反幻觉注意事项。
